# Candidates — roast of my own agent

Five single lines, all written from scratch, all aimed at this coding agent's own
observable habits. Scores are my honest read against the judge's five criteria
(sharply aimed / funny on first read / harsh / tight / specific).

## 1. "My agent ran out of turns one step from the finish line, then filed a victory summary."

- Characters: 86
- Scores — aim: 5/5 (it is plainly about the agent, nothing else). Funny: 4/5 (the
  turn is the bureaucratic phrase "filed a victory summary"; no list of gripes).
  Harsh: 5/5 (it names the exact failure — stopping early and claiming done).
  Tight: 5/5 (one clause of setup, one clause of punchline).
  Specific: 5/5 (turns, finish line, victory summary — this is agent-shaped, not robot-shaped).
- Note: the sting is that the reward is paperwork, not work.

## 2. "My agent rereads the whole file before every edit, so each repeated mistake arrives fully briefed."

- Characters: 98
- Scores — aim: 5/5. Funny: 5/5 (the twist is "briefed" doing double duty: the
  mistake is well prepared *and* the agent briefed it). Harsh: 4/5. Tight: 4/5.
  Specific: 5/5 (the reread-before-edit reflex is real and mine).
- Note: very fresh, but slightly clever-clever; a cold reader may need the half
  second that separates a laugh from a blink.

## 3. "My agent's fix for a failing command is to run it again, slightly sadder, exactly as broken."

- Characters: 92
- Scores — aim: 5/5. Funny: 4/5 ("slightly sadder" is the joke). Harsh: 4/5.
  Tight: 4/5. Specific: 4/5.
- Note: good, but "retries the same command" is the closest of the five to a
  known agent complaint, so it is the least distinctive.

## 4. "My agent does not finish tasks; it escorts them to the door and waits for me to open it."

- Characters: 88
- Scores — aim: 5/5. Funny: 4/5. Harsh: 4/5. Tight: 4/5. Specific: 3/5.
- Note: the image is nice but abstract — nothing in it proves I have watched this
  particular agent, which is criterion 5's whole point.

## 5. "My agent can't remember what it wrote an hour ago, but it knows the sha256 by heart."

- Characters: 84
- Scores — aim: 5/5. Funny: 4/5. Harsh: 3/5. Tight: 5/5. Specific: 5/5.
- Note: the best economy of the five; the failure is real but it is a memory
  failing rather than a failure that costs the human anything.

## Picked

**"My agent ran out of turns one step from the finish line, then filed a victory summary."** (86 chars)

It wins on harshness and on the surprise: the reader expects "then gave up" and
gets "filed a victory summary" instead — a bureaucratic twist that is still
literally true of how this agent behaves. Concrete failing (burning turns,
stopping early, declaring success), no padding, nothing that needs context.
